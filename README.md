# 散装汽油实名购油登记台

- 行业：石油（散装汽油销售实名登记）
- 技术栈：React、Vite、TypeScript、Zustand，数据保存在浏览器 localStorage
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

- 凭证件登记：姓名、身份证号、容器类型、车牌（可空）、本次升数；身份证校验位不通过无法提交。
- 同一证件当日累计达到 **20 升**的单据先进入“待核验区”，由站长输入口令确认后才能出油；未到限额的单直接待出油。
- 同一证件、同一分钟重复提交只保留一单（拦截第二单并提示已有单）。
- 撤销未出油的单，额度立即归还；撤销/补录后待核验单若累计回落到 20 升以下，自动回到待出油。
- 已出油记录冻结，不能撤销/改字段；只能“补录更正”，必须填写原因，原值在记录中保留并显示“原值 → 新值”。
- 老顾客再次录入证件号自动带出姓名、容器、车牌；顾客资料册与订单分键存储。
- 重开页面后可按身份证号（支持部分号码）+ 日期 + 状态回查，并显示当日累计额度。

演示站长口令：`888888`。

## 目录结构（按职责分层）

```
src/
  fuel/            领域层，与页面无关
    types.ts       数据模型（单据、补录、流水、顾客资料）
    config.ts      限额、站长口令、容器类型、存储键
    format.ts      本地日期/分钟键与时间展示
    customers.ts   顾客资料：证件校验/规范化、资料册维护
    quota.ts       限额判定：当日累计、初始状态、重复分钟、回落重判
    storage.ts     本机保存：订单/顾客/加油员分键读写（带版本）
    seed.ts        首次打开的演示数据
    store.ts       zustand 状态与所有业务动作
  components/
    RegisterForm.tsx  登记录入表单（含实时累计与超限预判）
    PendingPanel.tsx  待核验区（站长口令放行、未出油撤销）
    PinModal.tsx      站长确认口令窗
    RecordDesk.tsx    按证件/日期回查、出油、撤销、补录、流水
    AmendModal.tsx    已出油烟单的补录弹窗（必填原因、保留原值）
  App.tsx          页面组装、指标、提示条
```
