# 散装汽油实名购油登记台

- 行业：石油
- 技术栈：React、Vite、TypeScript、Zustand、Ant Design
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

纸质登记本的电子化替代：顾客出示身份证后，在同一页面完成实名登记、限额计算、站长核验、出油确认与历史回查。数据保存在本机浏览器 localStorage 中，刷新或重开页面不丢失，方便后续扩展接口、权限或打印能力。

## 功能规则

- **实名登记**：姓名、证件号（18 位身份证含校验位校验）、容器类型、车牌（可留空）、本次升数。证件号失焦时自动带出本机已登记顾客姓名。
- **限额判定**：同一证件按本地日期累计购油，**累计达到 20 升**的单据进入「待核验区」，填写站长姓名确认后方可出油；未满额单据登记后即为「可出油」。
- **重复拦截**：同一证件号在同一分钟内重复提交时拦截，仅保留首单。
- **撤销归还额度**：待核验 / 可出油（均未出油）的记录可撤销，撤销需填原因；撤销后当日累计立即减去该单升数。
- **冻结与补录**：出油后的记录冻结，姓名、证件号、升数不可改；只能补录容器、车牌、备注，必须填写原因与经办人，原值与变更过程保留在记录中。
- **回查**：记录列表支持按证件号、日期（默认今天）、状态筛选；展开行可看出油/撤销时间、站长确认人及补录痕迹。

## 目录结构

- `src/types.ts`：领域类型（记录、顾客、补录、状态）
- `src/lib/customer.ts`：顾客资料（证件号规范化/校验、车牌校验、顾客表维护）
- `src/lib/quota.ts`：限额判定（当日累计、20L 阈值、同分钟查重、日期工具）
- `src/lib/store.ts`：本机保存与状态流转（Zustand + localStorage 持久化）
- `src/lib/seed.ts`：首次打开的示例数据
- `src/components/`：页面（录入表单、待核验区、记录列表、补录弹窗）
- `src/App.tsx`：页面组装与顶部指标
